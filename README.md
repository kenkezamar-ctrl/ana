# موقع عمار كنزاري البحثي

هذا المستودع مخصص لحفظ نسخة مصدرية منظمة من محتوى الموقع المنشور على WordPress.com.

- الموقع: https://amarkenzari.wordpress.com/
- الهوية: عمار كنزاري | باحث حر
- منصة النشر الأساسية: WordPress.com
- الفرع الأساسي: main

## بنية المستودع

- `wordpress/pages/`: نسخ من محتوى صفحات الأبحاث بصيغة HTML تتضمن تعليقات وكتل Gutenberg الأصلية قدر الإمكان.
- `wordpress/site-manifest.md`: فهرس الصفحات وروابطها وملاحظات المزامنة.

## تنبيه مهم

هذا المستودع نسخة أرشيفية ومصدرية للمحتوى، وليس نسخة تشغيلية كاملة من WordPress؛ فهو لا يحتوي قاعدة البيانات أو إعدادات القالب أو الوسائط أو الإضافات أو إعدادات الموقع الخاصة. ولا يؤدي تعديل الملفات هنا إلى تحديث الموقع المنشور تلقائيًا على الخطة المجانية.

يجب التعامل مع WordPress بوصفه المصدر المنشور الأساسي، ثم حفظ نسخة جديدة في GitHub بعد كل تحديث مهم. لا تضع كلمات مرور أو مفاتيح API أو بيانات دخول في هذا المستودع.
