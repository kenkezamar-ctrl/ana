## حدود الأرشيف والمزامنة

هذا المستودع يحفظ المحتوى المصدر لصفحات Gutenberg السبع، والمنشورين البحثيين، وجزأي الترويسة والتذييل من القالب. ولا يمثل نسخة كاملة من WordPress؛ فهو لا يشمل قاعدة البيانات أو إعدادات القالب أو مكتبة الوسائط أو الإضافات أو إعدادات الحساب.

WordPress هو المصدر المنشور الأساسي. تعديل الملفات في GitHub لا يحدّث الموقع تلقائيًا على الخطة المجانية؛ لذلك تُزامن الملفات بعد كل تعديل منشور مهم. لا تضع كلمات مرور أو مفاتيح API أو بيانات دخول في هذا المستودع.
