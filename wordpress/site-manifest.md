## فهرس منشورات Figshare

تُجمع معرّفات DOI الخمسة وروابط سجلاتها الرسمية في [فهرس منشورات Figshare](../research/figshare-publications.md). ويظل Figshare مرجع بيانات النشر، بينما يؤدي GitHub وظيفة الفهرسة والأرشفة.

## طريقة التحديث

1. يُحرر المحتوى في WordPress أولًا.
2. تُستخرج النسخة الأحدث من الصفحة المنشورة.
3. يُحدّث الملف المقابل في هذا المستودع مع رسالة commit واضحة.
4. تُراجع الفروقات قبل اعتماد أي تعديل.

## حدود الأرشيف

يحفظ هذا الأرشيف محتوى الصفحات السبع والمنشورين المنشورين وجزأي الترويسة والتذييل بصيغة كتل WordPress/Gutenberg. ولا يشمل تلقائيًا مكتبة الوسائط الأصلية، إعدادات القالب، القوائم، عناصر التخصيص، التعليقات، المستخدمين، أو قاعدة بيانات WordPress كاملة. ولا ينبغي نشر ملفات HTML هذه مباشرة إلى مجلد القالب أو جذر الموقع؛ فهي ملفات أرشيف للمحتوى وليست ملفات قالب قابلة للنشر.
